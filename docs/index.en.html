Debloat Android, no root.

Remove vendor apps over ADB, and put them back in one click.

Linux AppImage Windows .exe macOS .zip

Version 1.6.0, MIT licence. Needs ADB on the computer.

Nothing comes pre-checked

You check every app yourself. Vital OS components stay locked.

The CLI keeps the same guardrails

Same database, same refusals, same restore ledger. It answers in French.

One file, plus ADB

On the phone, turn on USB debugging in the developer options.

Linux

debloat-android-linux.AppImage runs as is, nothing to install.

sudo apt install adb

Windows

DebloatAndroid.exe and debloat-cli.exe, standalone executables. ADB comes from the platform-tools.

set ADB_PATH=C:\platform-tools\adb.exe

macOS

debloat-android-macos.zip: unzip, then open DebloatAndroid.app.

brew install --cask android-platform-tools

One click puts it all back

The backup manager reinstalls what you removed.

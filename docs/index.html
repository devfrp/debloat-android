Retire les applis constructeur via ADB, et remets-les en un clic.

Rien n’est coché d’office

Tu coches chaque appli toi-même. Les composants vitaux restent verrouillés.

Un fichier, plus ADB

Sur le téléphone : active le débogage USB dans les options développeur.

Linux

debloat-android-linux.AppImage se lance tel quel, rien à installer.

sudo apt install adb

Windows

DebloatAndroid.exe et debloat-cli.exe, exécutables autonomes. ADB vient des platform-tools.

set ADB_PATH=C:\platform-tools\adb.exe

macOS

debloat-android-macos.zip : décompresse, puis ouvre DebloatAndroid.app.

brew install --cask android-platform-tools

Le gestionnaire de backups réinstalle ce que tu as retiré.
